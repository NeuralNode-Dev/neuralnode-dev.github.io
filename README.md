## 💻 四、全平台代理客户端教程与配置指南

### 1. Windows 桌面端
*   **[Clash Verge Rev (推荐)](https://github.com/clash-verge-rev/clash-verge-rev)**：基于 Meta 内核，界面现代，支持 Hysteria 2 与自定义分流规则。
    *   *导入步骤*：打开软件 -> 点击左侧「订阅」-> 粘贴订阅 URL -> 点击「导入」并启用。
*   **[v2rayN](https://github.com/2dust/v2rayN)**：经典老牌 Windows 代理工具，功能强大。
    *   *导入步骤*：顶部菜单「订阅分组」->「订阅分组设置」-> 点击「添加」-> 填入 URL 并更新订阅。

### 2. Android 安卓移动端
*   **[Clash Meta for Android](https://github.com/MetaCubeX/ClashMetaForAndroid)**：目前安卓端体验最佳的分流客户端。
*   **[v2rayNG](https://github.com/2dust/v2rayNG)**：轻量简洁，配置极其傻瓜化。

### 3. iOS / iPadOS 苹果移动端
*   **Shadowrocket (小火箭)**：需使用非中国大陆区 Apple ID 在 App Store 下载。
    *   *导入步骤*：右上角「+」-> 类型选择 `Sub / Subscribe` -> 粘贴 URL -> 点击「保存」-> 划下刷新。
*   **Quantumult X (圈X)** / **Stash**：适合进阶策略分流与自定义脚本用户。

### 4. macOS 苹果电脑

## ❓ 六、常见问题与排查 FAQ

#### Q1: 订阅导入后提示 `Connection Refused` 或超时怎么办？
> 答：请先检查本地客户端是否开启了「系统代理」；若使用 Clash，请确保内核版本支持对应的协议（如 Hysteria 2 需要 Meta 内核支持）。

#### Q2: 如何防止国内流量误走代理导致访问变慢？
> 答：在客户端设置中将路由模式切换为 **「Rule (规则分流)」** 或 **「绕过大陆IP / GeoIP CN」**，即可实现国内流量直连、国外流量走节点。

#### Q3: 为什么部分节点无法解锁 ChatGPT 或 Netflix？
> 答：部分公共节点 IP 被 OpenAI 或 Netflix 限制，建议使用 **[云猫网络](https://cloud.yuncat.top)** 的 AIGC / 流媒体专线节点。
